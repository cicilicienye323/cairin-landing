# cairin-landing

Marketing landing page for cairin, a seller payout ledger. Built with Next.js as a static export and hosted on GitHub Pages.

## Run locally

Requires Node.js 24.

```
npm install
npm run dev
```

Open http://localhost:3000/cairin-landing/ (the site lives under the GitHub Pages subpath).

## Test and build

```
npm test
npm run build
```

The static site is written to `out/`.
